# Deep-Dive Analysis & Interactive Dashboarding

## Objective
To analyze sales data and build an interactive Power BI dashboard for business insights.

## KPIs
- Total Sales
- Total Orders
- Average Sales
- Total Quantity

## Analysis Performed
- Customer Segmentation
- City-wise Sales Analysis
- Category-wise Sales Analysis
- Gender-wise Analysis
- Monthly Sales Trend

## Tools Used
- Power BI
- DAX
- Excel

## Key Insights
- High-value customers contribute the majority of revenue.
- Male customers contribute slightly more sales than female customers.
- Top cities drive significant sales performance.
- Sales vary across months, indicating seasonal trends.

## Deliverables
- Power BI Dashboard
- Dashboard Screenshot
- Analysis Report
